# pen-story-animation

Claude Code skill：把分鏡圖或插圖加上故事腳本，做成「一支筆先勾線、再上色、畫完換頁」的筆繪說故事動畫 MP4，含中文旁白、字幕與音效。

使用方式與需求見 [SKILL.md](SKILL.md)。

## 安裝

```bash
git clone https://github.com/kingvincentwang/pen-story-animation.git ~/.claude/skills/pen-story-animation
```

需要 Windows、Python（opencv-python、numpy）、ffmpeg、Node 和 HyperFrames。
